# 🌐 Personal Portfolio

![Portfolio Preview](https://portfolio-mu-virid-41.vercel.app/) 
_A modern, minimalist, and responsive developer portfolio built to showcase my projects, skills, and journey._

---

## ✨ Features

- 🎨 **Modern UI/UX** – Clean and minimal design with focus on usability.
- ⚡ **Responsive Layout** – Works perfectly on desktop, tablet, and mobile.
- 🌗 **Dark Mode** – Smooth toggle for light/dark theme (if added).
- 🖼️ **Project Showcase** – Cards with live demos & GitHub links.
- 📖 **About Me & Skills** – Highlighting my tech stack and journey.
- 📬 **Contact Form** – Easily reachable with integrated form & social links.

---

## 🛠️ Tech Stack

- ⚛️ **React** – Component-based architecture for a scalable portfolio.
- 🎨 **Tailwind CSS** – Utility-first CSS for rapid and consistent styling.
- 🌀 **Framer Motion** – Smooth animations and transitions.
- 🔗 **React Router** – Seamless navigation between pages.
- 📧 **EmailJS** (or your method) – Contact form integration.

---

## 🚀 Getting Started

Clone this repository and run it locally:

```bash
# Clone the repo
git clone https://github.com/your-username/your-portfolio.git

# Navigate to folder
cd your-portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```
